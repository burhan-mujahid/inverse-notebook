# Security reporting

To report a vulnerability, email **[burhanmujahid552@gmail.com](mailto:burhanmujahid552@gmail.com)** with the subject **Inverse security report**. Include the affected commit or version, reproduction steps, expected impact, and a minimal example without private data.

Please report exploitable vulnerabilities privately before opening a public issue. Ordinary calculation errors and usability bugs can use the public bug template unless they have a security impact.

Inverse is an early prototype. Security fixes target the current `main` branch; there is no long-term support policy or guaranteed response time. The development server binds to loopback and is intended for local use. Imported files are validated notebook data, not executable model definitions.
